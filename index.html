Why StormBreaker

Built to perform, made to last

Real engineering, tracked upstream and built for balance. Many official and unofficial ROMs have shipped StormBreaker as their stock kernel.

Tuned for speed

Carefully tuned schedulers, governors and I/O that keep everyday scrolling and gaming smooth without giving up stability.

Deep upstream work

Upstreaming the OEM kernel source onto the latest Linux-stable, with regular LTS, ACK and CLO merges and features ported from newer upstreams.

Backports

Useful features pulled back from newer kernels to the version your device runs, like RCU for faster file operations and BBR for networking.

Battery friendly

Idle and thermal tuning that keeps drain in check, for better standby and cooler temperatures under load.

Fully open source

Every line lives on GitHub under the GPL. Clone it, audit it, build it, or send a pull request.

Under the hood

Stability first. We don't ship tweaks that trade it away for a benchmark number.

Performance

  • RCU backports for faster file operations
  • Schedtune boost for snappier interaction
  • BBR congestion control, backported 4.14 to 4.4 LTS
  • TCP stack backports for throughput and latency
  • vDSO32 for low-overhead userspace time calls
  • srandom for a faster /dev/urandom
  • Plenty more under-the-hood tuning

Stability

  • Modern Clang compiler optimizations
  • Bug fixes and security hardening
  • LZ4-compressed zRAM
  • Regular Linux-stable and CLO merges
  • TTL fix and more

Battery

  • Trimmed debug logging
  • GPU power optimizations
  • Idle wakelock tuning
  • Display panel power tuning
  • Scheduler tuning for efficiency
  • System-wide power-efficient workqueues
