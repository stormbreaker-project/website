why stormbreaker

Built to perform, made to last

Real engineering, tracked upstream and built for balance. Official and unofficial ROMs have shipped StormBreaker as their stock kernel.

01

Deep upstream work

We rebase the OEM kernel source onto the latest Linux-stable and land LTS, ACK, and CLO merges by hand, then pull features back from newer upstreams. This is the part most kernels skip.

02

Tuned for speed

Schedulers, governors and I/O tuned so everyday scrolling and gaming stay smooth, without trading away stability.

03

Backports

Modern features pulled back to the kernel your device actually runs, like BBR for networking and scheduler improvements from newer trees.

04

Battery friendly

Idle and thermal tuning that keeps drain in check, for better standby and cooler temperatures under load.

05

Fully open source

Every line lives on GitHub under the GPL. Clone it, audit it, build it, or send a pull request.

under the hood

Stability first. We don't ship tweaks that trade it away for a benchmark number.

# performance
+BBR congestion control, backported from 4.14 to 4.4 LTS
+Scheduler tuning: schedutil and schedtune boost
+vDSO32 mapped for low-overhead userspace time calls
+srandom, an add-on module for a faster /dev/urandom
+Selected RCU and TCP updates from newer kernels
+Plenty more under-the-hood tuning
# stability
+Modern Clang compiler optimizations
+Bug fixes and security hardening
+LZ4-compressed zRAM
+Regular Linux-stable and CLO merges
+TTL fix and more
# battery
+Trimmed debug logging
+GPU power optimizations
+Idle wakelock tuning
+Display panel power tuning
+Scheduler tuning for efficiency
+System-wide power-efficient workqueues
