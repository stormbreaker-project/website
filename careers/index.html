Join the team.

We are a self-funded, open-source collective. We cannot pay you, but if you want to learn how Android really works, from the kernel up, there are very few better places to do it.

What we can’t offer
  • A salary, equity, or any money. StormBreaker is self-funded and always has been.
  • A 9-to-5, a manager, or a contract. This is volunteer, open-source work.
  • Deadlines that come before your studies, job, or life. Those come first.
What we can
  • Real mentorship from people who ship kernels, an OS, and apps used by a million-plus.
  • Code that actually ships to real devices, not toy projects or busywork.
  • A public portfolio of serious low-level and Android work with your name on it.
  • Ownership. Pick up a device, an app, or a subsystem and make it yours.
  • A place to learn things most courses never touch: kernels, AOSP internals, toolchains.

Where you’d fit

Pick the layer that excites you. None of these need a résumé, just curiosity and follow-through.

Kernel Developer

CLinuxkernel

Maintain device kernel trees: LTS bumps, CLO merges, backports, and chasing down regressions on real hardware.

You’ll learn
  • Real Linux kernel development
  • ARM64 / device debugging
  • Reading and porting upstream patches

You know some C and are not scared of a stack trace. Kernel experience is a bonus, not a requirement.

ROM / Framework Engineer

AOSPJavaC++

Work on PVOT OS, our AOSP/LineageOS fork. Framework customizations, theming, and keeping the build green.

You’ll learn
  • The AOSP build system end to end
  • Android framework internals
  • Working in a huge codebase

You are comfortable with Java and patient with long builds. Curiosity beats prior AOSP experience.

App Developer

KotlinCompose

Build and maintain our de-Googled app suite in Kotlin and Compose: Messages, Gallery, Aperture, and more.

You’ll learn
  • Modern Android & Jetpack Compose
  • Shipping and maintaining real apps
  • Privacy-first engineering

You know some Kotlin, or you know Java and want to learn Compose. We will help you get there.

UI/UX & Design Systems

Composedesign

Grow PvotLib, the shared component library every app is built from: components, tokens, motion, docs.

You’ll learn
  • Building a real design system
  • Compose theming & API design
  • Design that survives contact with code

You care how things look and feel, and you can turn a design into a reusable component.

Web & Docs

Astrowriting

Improve this website and the docs across every repo. The writing that makes everything else usable.

You’ll learn
  • Astro & modern static web
  • Technical writing that people actually read
  • Turning tribal knowledge into docs

You can write clearly, or you know a bit of web. Great first way in if you are new.

Device Maintainer / Tester

testingtriage

Bring up and test builds on real devices, reproduce bugs, gather logs, and triage what comes in.

You’ll learn
  • Device bring-up from scratch
  • Debugging on real hardware
  • How a release actually happens

You have a device or two and the patience to flash, break, log, and repeat.

What we actually look for

CuriosityYou want to know how things work, not just that they do.
Follow-throughYou finish what you pick up, or you say when you can’t.
KindnessYou are patient with people and generous with what you know.
ConsistencyA little, often, beats a burst that vanishes.

How to join

  1. Find a project on the where to contribute page and send a first patch.
  2. Say hi on Telegram or Discord and tell us what you want to learn.
  3. Stick around. Maintainers are just contributors who kept showing up.
